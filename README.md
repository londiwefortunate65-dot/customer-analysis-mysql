
# Customer and Order Analysis Using MySQL

## Project Overview
This project uses MySQL to explore customer and order data, practise data cleaning, and answer business questions using SQL. The analysis focuses on customer characteristics, purchasing behaviour, product preferences, order values, and profitability.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Dataset
The project uses customer and order datasets containing customer details, product information, purchase amounts, order quantities, prices, and discounts.

The datasets were loaded into MySQL for cleaning and analysis.

## Data Cleaning
The data preparation process included:
- Checking for duplicate customer records.
- Investigating missing and blank values.
- Standardising inconsistent category values.
- Reviewing customer and product identifiers.
- Checking date and numeric fields for data quality issues.

## Customer Analysis
The customer analysis explored:
- Customer demographics, including age and gender.
- Customer locations.
- Purchase amounts and purchasing patterns.
- Product preferences, including season, colour, and size.
- Subscription status, discounts, and payment methods.
- Purchase frequency and customer ratings.

## Order Analysis
The order analysis explored:
- Order data and order dates.
- Cost price, list price, and quantity.
- Discount percentages.
- Sales value and estimated profit.

Profit was calculated using the following formula:

`Profit = (List Price - Cost Price) × Quantity`

## SQL Skills Demonstrated
- SELECT statements and filtering.
- Aggregate functions such as COUNT, SUM, and AVG.
- GROUP BY and ORDER BY.
- CASE statements for categorisation.
- Handling missing values and duplicate records.
- Common Table Expressions (CTEs).
- SQL functions and stored procedures, where applicable.
